Welcome to DevOps Kubernetes

This application is automatically built, containerized, pushed to Docker Hub, and deployed to a Kubernetes cluster using Jenkins CI/CD.

Technology Stack

GitHub

Source code is maintained in GitHub. Jenkins receives a webhook whenever new code is pushed.

Jenkins

Jenkins performs checkout, testing, Docker image creation, tagging and deployment.

Docker

The application is packaged as a Docker image and pushed to Docker Hub.

Kubernetes

Kubernetes manages application Pods and provides self-healing and rolling deployment capabilities.

Nginx

Nginx serves this web application from inside the Kubernetes Pods.

CI/CD

Every new Jenkins build creates a new Docker image using the Jenkins build number.
